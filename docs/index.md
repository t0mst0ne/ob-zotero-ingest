# OB–Zotero Academic Ingestion

開源 Chrome 擴充功能。從你正在閱讀的學術論文擷取書目與全文，寫入本機 Obsidian Vault，並可選擇對齊 Zotero。

Open-source Chrome extension that extracts an academic article into a local Obsidian vault, with optional Zotero alignment.
